📋 SecProgram Project Technical Blueprint
Project Overview
Purpose: Cloud-based web app for Congregation Secretaries to manage 100+ publishers, monthly service reports, S-21 publisher record cards, and congregation service totals.

Legacy System: MS Access database (Publishers, MonthlyRecord, Record tables across 12+ years of data).

Target Stack (100% Free): Python (FastAPI/Flask), PostgreSQL (Supabase/Neon), Bootstrap 5, PDF Export (ReportLab/WeasyPrint), Hosting (Render/PythonAnywhere).

1. CongInfo (Congregation Settings - 1 Row)
======================================================================
- MONTH_            : Text (Active Month Name)
- NUM               : Integer (Active M/Y ID Pointer)
- Congregation      : Text (Congregation Name)
- CongNumber        : Text (Branch Congregation ID)
- Address           : Text (Kingdom Hall Address)
- Province          : Text (Province / State)
- CBOE              : Text (Coordinator Name)
- SO                : Text (Service Overseer Name)
- SEC               : Text (Secretary Name)

======================================================================
2. GROUPS (Field Service Groups - ~6 or more Rows)
======================================================================
- id                : Primary Key
- Group             : Text / Integer (Group Number/Name)
- Overseer          : Text (Overseer Name / ID)
- Assistant         : Text (Assistant Name / ID)
- MeetingPlace      : Text (Ministry Meeting Location)
- Remarks           : Text (Group Notes)

======================================================================
3. PUBLISHERS (Publisher Master Records - ~100 Rows)
======================================================================
- IDPub             : Primary Key (Legacy Access ID)
- FNAME             : Text (First Name)
- MName             : Text (Middle Name)
- LName             : Text (Last Name)
- Nname             : Text (Nickname)
- Birthdate         : Date
- Male              : Boolean / Char (Y/N)
- Female            : Boolean / Char (Y/N)
- Address           : Text
- TelCp             : Text (Mobile Phone)
- Baptism           : Date
- Elder             : Boolean (Y/N)
- MS                : Boolean (Y/N)
- RP                : Boolean (Y/N)
- RpNumber          : Text (Pioneer Registration Number)
- RpDateStarted     : Date
- GROUP             : Foreign Key -> GROUPS.id
- Status            : Text ("Moved Out", "Removed", "Disqualified", or NULL for Active)
- Started           : Integer (First Month/Year ID Index)

======================================================================
4. MonthlyRecords (Congregation Monthly Summaries - 12 Rows/Year)
======================================================================
- ID                : Primary Key
- NUMBER            : Integer (M/Y ID Index)
- MONTH_            : Text / Integer (Month)
- Year              : Integer (Calendar Year)
- ServiceYear       : Integer (Service Year)
- AttendcMidweekTotal : Integer (Total Midweek Attendance)
- AttendcPublickTotal : Integer (Total Weekend Attendance)
- NoMtgs1           : Integer (Midweek Meetings Count)
- NoMtgs2           : Integer (Weekend Meetings Count)
- ActivePublishers  : Integer (Locked Active Publisher Count)

======================================================================
5. RECORDS (Individual Monthly Service Reports - Thousands of Rows)
======================================================================
- IdPubs            : Foreign Key -> PUBLISHERS.IDPub
- NUMBER            : Integer (Actual Service Month M/Y ID)
- Date_entered      : Integer (Processing/Submission M/Y ID for Late Reports)
- HRS               : Integer / Float (Field Service Hours)
- AUX               : Boolean (Y/N - Auxiliary Pioneer for Month)
- REMARKS           : Text (Flag keywords: "RP", "RP Moved In", "New UBP", etc.)
- Note              : Text (General Secretary Remarks)

(async () => {
    const db = await new Promise((resolve, reject) => {
        const req = indexedDB.open("CongregationDB");
        req.onsuccess = () => resolve(req.result);
        req.onerror = () => reject(req.error);
    });

    const tx = db.transaction("PUBLISHERS", "readonly");
    const store = tx.objectStore("PUBLISHERS");

    const rows = await new Promise((resolve, reject) => {
        const req = store.getAll();
        req.onsuccess = () => resolve(req.result);
        req.onerror = () => reject(req.error);
    });

    rows.sort((a, b) =>
        String(a.LName ?? "").localeCompare(
            String(b.LName ?? ""),
            undefined,
            { sensitivity: "base" }
        )
    );

    console.log(`📋 Total PUBLISHERS: ${rows.length}`);

    console.table(
        rows.map(p => ({
            Name: `${p.LName ?? ""}, ${p.FNAME ?? ""}`.trim(),
            IDPub: p.IDPub,
            LName: p.LName ?? "",
            FNAME: p.FNAME ?? "",
            MName: p.MName ?? ""
        }))
    );

    db.close();
})();

const publishers = await new Promise((resolve, reject) => {
    const r = tx.objectStore("PUBLISHERS").getAll();
    r.onsuccess = () => resolve(r.result);
    r.onerror = () => reject(r.error);
});

const records = await new Promise((resolve, reject) => {
    const r = tx.objectStore("RECORDS").getAll();
    r.onsuccess = () => resolve(r.result);
    r.onerror = () => reject(r.error);

const result = publishers
